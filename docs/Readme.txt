To run the "adk web" command in PyCharm:
- Click "Edit Configurations" at the top right of the PyCharm window.
- Add a new configuration for a Shell Script or Python, depending on your setup.
- Set the command to `adk web`.

To be plug and play with the ADK, ensure you change the absolute path from config.yaml and get_config.py

For more information, see the official documentation:
https://google.github.io/adk-docs/
